最近重新整理博客，也把接下来想做的事情记在这里。比起不断增加入口，更希望每个页面都能认真读、顺手用。

这是一份公开的建设记录。下面的勾选标记随文章更新，不能在这里直接保存自己的任务。

## 阅读与布局

- [x] 首页与文章用统一的横幅、导航和卡片组织。
- [x] 在首页接上文章、专题与开发记录。
- [x] [本机文章收藏](/saved/)：在阅读工具里收藏文章，稍后回看；支持取消与同浏览器跨标签更新。
- [x] 搜索按需加载全文索引，按文章、工具、作品筛选；加载失败可重试，返回时保留关键词。
- [x] 目录锚点适配固定导航，回顶工具显示整页进度；公开索引排除模板和私人入口。
- [x] 统一正文、清单、提示框和代码样式；文章图片支持大图切换与键盘操作。
- [x] 补充专注阅读的 Esc 退出、分享失败后的手动复制，以及随内容变化的目录。
- [x] 外观面板可切换封面卡片与紧凑列表；首次访问采用静态壁纸，动态背景响应减少动态效果与省流量设置。
- [x] 写作支持步骤、内容标签页和代码分组，复制失败时提供手动复制。
- [x] 在桌面浏览器完成六种宽度、手机布局、键盘与深色主题检查；实体手机和屏幕阅读器仍需单独验收。

## 已经可以使用的工具

- [x] [WebHID 调试工具](/tools/hid/)：按协议手动发送指令并观察回包。
- [x] [WebHID 抓包脚本](/tools/webhid-workbench/)：把页面操作与报文对应起来。
- [x] [RK 键位对齐](/tools/key-align/)：在背景图上调整按键区域。
- [x] [音乐播放器](/music/)：支持独立音乐页、暂停、切歌和播放进度记忆。

## 接下来想做的事

- [x] [网页本地待办](/todo/)：保存、修改、完成任务，支持回收站和导入导出备份。
- [x] 确定私人相册方案：[ChronoFrame 本机接入](/photos/)，准备独立的数据目录与备份恢复工具。
- [x] 本机相册已运行，完成真实照片备份、恢复启动和未登录访问拦截检查。
- [ ] 在浏览器完成私人相册登录、看图与退出验收。
- [x] 在同一标签里切换博客文章、归档、作品介绍和音乐页时连续播放；刷新、关闭标签与进入独立工具页面会停止。
- [x] 整理[站点收藏](/friends/)的分组、用途搜索、随机发现和可复制的本站信息。

网页待办的数据只保存在当前浏览器，不上传任务，也不与 Windows 桌面待办共享数据。换设备可导出 JSON 后导入；清除网站数据前请先备份。

私人相册选用独立的 ChronoFrame，改为原生本机运行方案；照片和备份不进入博客公开目录。相册入口不代表服务已经在线，手机跨设备访问和公开部署尚未接入。
