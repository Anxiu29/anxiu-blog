# 用户壁纸与动态背景实施计划

> 使用 superpowers:executing-plans，在现有授权目录自行执行，末尾一次只读审查。

**Goal:** 用用户提供的四张图片替换上一轮图库，移除默认/晴空/暮色选项，接入一张可暂停的静音循环动态壁纸。
**Architecture:** 保留 Astro 面板与现有 IndexedDB 本地上传；背景模型只保留 image/video/color；媒体声明集中在 background-images.ts。独立 background-video.ts 管理视频、可见性、减少动态效果和播放失败。appearance.ts 连接模式、图库、滑块和持久化。
**Tech Stack:** 原生 HTMLVideoElement、CSS、TypeScript；现有 sharp；本机 FFmpeg 处理衍生资源，无新依赖。
**Spec:** 用户本轮消息及四张 JPG/一个 MP4；授权细节自行决定，无需重新确认。

## Constraints / decisions
仅本地，不提交/推送/部署；不改原始媒体、工具、下载、游戏；四图不重绘，只缩放压缩。旧四图从网页图库和资源中撤下。新初始壁纸选第一张“云下小憩”，遮罩40%、模糊0，重置也回此图；“默认”不作为选项。纯色和本地图片继续支持。
视频保留完整约20秒，1080p降至30fps、H.264/yuv420p、移除音轨、faststart；点击动态卡片才加载。静音/循环/playsinline，提供暂停/播放（选择与暂停持久化）；离开动态模式释放媒体；隐藏标签页暂停；减少动态效果先显示封面，用户可以手动播放；播放失败显示封面和提示。
沿用当前工程（已有大量未提交工作与预览依赖此目录），不迁移/不创建新工作树。QA脚本和截图放仓库外scratch。
